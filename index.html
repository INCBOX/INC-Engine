The entire contract

Three functions.
One header.

That's the full API surface. Init, Tick, Shutdown. Your module owns everything inside. The kernel never touches your internals — renderer, physics, simulation, audio. All yours.

Modules you build are yours. INC claims nothing.

INC Module — Hello World 
// The entire INC module contract.
// Same pattern whether you're printing
// text or running a universe sim.

#include <interface_module.h>
#include <stdio.h>

static void HelloWorld_Tick(float dt) {
    printf("Hello, World!\n");
}

static int HelloWorld_Init(
    IModule *self,
    IRuntimeContext *ctx,
    void (**tick)(float))
{
    *tick = HelloWorld_Tick;
    return 1;
}

static void HelloWorld_Shutdown(IModule *self) { }

INC(HelloWorld_Init, HelloWorld_Shutdown)

Dead simple deployment

Drop it in. It runs.

01
Build your module
Implement Init, Tick, Shutdown. Stamp with INC(). Compile to DLL or .so.
02
Drop in /bin
Place the DLL and a .manifest file in the /bin folder. No config. No registry.
03
Run INC.exe
Kernel scans /bin, resolves dependencies, loads in order, starts ticking.
04
Hot reload
Swap the DLL at runtime. Kernel detects the change and reloads automatically.
