▸ the entire contract

Three functions.
One header.

Your module owns everything inside — renderer, physics, audio, simulation. The kernel never touches your internals.

Modules you build are yours. INC claims nothing.

module_hello_world.c 
// entire INC module contract.
// same pattern: hello world → universe sim.

#include <interface_module.h>
#include <stdio.h>

static void Hello_Tick(float dt) {
    printf("Hello, World!\n");
}

static int Hello_Init(
    IModule        *self,
    IRuntimeContext *ctx,
    void          (**tick)(float))
{
    *tick = Hello_Tick;
    return 1;
}

static void Hello_Shutdown(IModule *self) { }

INC(Hello_Init, Hello_Shutdown)

▸ deployment

Drop it in. It runs.

01
Build your module
Implement Init, Tick, Shutdown. Stamp with INC(). Compile to DLL or .so.
02
Drop in /bin
Place the DLL and .manifest in /bin. No config. No registry. No build system.
03
Run INC.exe
Kernel scans /bin, resolves dependencies, loads in order, starts ticking.
04
Hot reload
Swap the DLL at runtime. Kernel detects the change and reloads in 16ms.
